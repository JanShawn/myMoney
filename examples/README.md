# 範例資料

[`myMoney-demo-data.json`](./myMoney-demo-data.json) 是一份完全虛構的完整備份，可用來預覽所有主要頁面。

內容包含：

- 8 個帳戶項目，包含台幣、美元、日圓、其他資產與負債。
- 3 筆虛構投資持倉，避免與真實商品及即時價格混淆。
- 1 份已對齊的現金驗算明細。
- 6 筆週期收支項目。
- 6 個月的資產盤點與虛構市場數字。

使用方式：下載 JSON 後，到 myMoney 的「設定」頁選擇「從 JSON 復原」。確認復原前，系統會先保留目前瀏覽器資料的近期版本。

> 所有名稱、帳戶、金額、價格、匯率與市場數字都只供介面展示，不代表任何真實人物、金融商品或投資建議。
