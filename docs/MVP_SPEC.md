# myMoney MVP 鎖定方案

## 核心判斷

採用單一 Nuxt 靜態 SPA。JSON 是帳戶、持倉與歷史快照的主要資料格式；Excel 只作為快照匯出格式。

## 儲存策略

1. 支援 File System Access API 時，使用者可選擇或建立本機 data.json。
2. 取得權限後，每次修改直接寫回同一個 JSON。
3. 未連結檔案或瀏覽器不支援時，使用 IndexedDB 保存。
4. 每次保存前把上一版放入 IndexedDB，最多保留 5 份。
5. 提供 JSON 匯入／下載，作為跨瀏覽器與手動備份機制。
6. 未來線上化時新增 Remote Storage Adapter，不修改頁面與領域計算。

## MVP 範圍

- 自由新增、重新命名、排序、編輯與刪除兩層帳戶結構；刪除前必須再次確認。
- 流動性只影響「可立即動用」統計：立即可用會計入，可變現與受限制不計入；不影響已納入資產的總資產與淨資產。
- 群組可永久刪除；刪除前需二次確認，並明確列出群組內項目與驗算草稿會一起移除。
- 現金、股票、債券、其他資產與負債分類。
- TWD、USD、JPY 三種幣別；USD、JPY 以每日參考匯率換算並獨立統計為外幣資產。
- 立即可用、可變現、受限制三種流動性。
- 投資持倉保存代號、數量、類別、方向與價格。
- 投資持倉可用上移／下移手動排序，順序會一併保存。
- 現金驗算會依帳戶保留尚未清除的驗算草稿，套用時更新帳戶最後結果。
- 每日一筆 JSON 快照；同日再次保存會更新原紀錄。
- 預設資料保存在目前瀏覽器的 IndexedDB；連結 data.json 後，每次修改會同步寫入檔案與 IndexedDB，方便隨專案搬移到另一台電腦。
- JSON 匯出／匯入交換完整資料；Excel 只匯出資產盤點歷史。
- 資產盤點的帳戶餘額與持倉市值由來源頁面自動彙整，盤點頁不提供第二個資產編輯入口。
- 金額、數量、價格與市場點數的輸入及顯示使用千分位，實際保存仍為數值。
- 四組核心圖表與最近驗算時間。
- Dashboard 顯示可動用現金、股票與債券的目前比例，並依可保存的目標比例即時計算投入／保留差額。
- Dashboard 顯示資產盤點與加權指數的標準化對照圖，以及最近盤點時保存的實際大盤點數與 240MA。
- 加權指數與 240MA 使用相同的證交所每日資料；240MA 為最近 240 個交易日收盤指數的算術平均。
- 台股最新收盤價優先使用 FinMind 公開日行情 API，證交所／櫃買中心商品快取僅作為失敗備援；介面提供 Yahoo 股市核對連結。
- Excel 快照匯出。

## 非目標

- 登入、多使用者、銀行與券商串接。
- 交易成本、損益、股利與盤中報價。
- 讓靜態網站無權限存取任意本機路徑。

## 主要風險

- 本機 JSON 被外部修改：比較檔案修改時間並阻擋覆寫，要求重新載入。
- 檔案權限失效：保留 IndexedDB 資料並提示重新授權。
- 瀏覽器不支援直接檔案存取：改用 IndexedDB 與 JSON 匯入／下載。
- TWSE／TPEx 跨來源請求失敗：名稱與收盤價改用建置時保存的官方資料快取，海外或未收錄商品才改用手動輸入。

## 完成條件

- npm run build 可產生可獨立部署的 .output/public。
- Network 不需要 3001 API 或 Express。
- 可連結、建立、讀取、更新與重新載入 data.json。
- 未連結 JSON 時重新整理後資料仍存在 IndexedDB。
- 同日快照更新與所有資產計算測試通過。
